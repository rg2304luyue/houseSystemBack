## 覆盖范围

- 实名签约、备案、押金与入户。
- 房屋安全、腾退、争议解决。
- 房源真实性、中介收费、网络平台责任。
- 合同形式、备案效力、维修、正常损耗。
- 转租、改装、所有权变动及优先购买。
- 欠租、不定期租赁、安全风险、退租与续租。

## 边界与维护

本批资料是法条节选，不包含完整司法解释和地方实施细则，不应据此承诺个案处理结果。采集日期不是“已全面确认截至该日没有修订”的声明。上线前及政策更新时仍需复核效力。

本次没有收入未能核实的长沙备案材料、办理时限、公积金租房提取额度、补贴标准。湖南省直公积金与长沙市公积金不能混用；历史公告和未生效政策不能当作现行办理依据。

现有加载器仍将一般文档标记为 `source_required`；本批不修改加载器，也不把文档自动提升为产品审核通过状态。TXT 中的来源、生效日期、采集日期、适用范围会继承到分块元数据。

新增文件后必须运行后端 `.venv\Scripts\python.exe -m core.rag.indexer` 才能更新向量索引；仅复制 TXT 不会自动生效。执行前备份 `core/core/chroma_db` 与 `core/rag_state`，不需要 `--rebuild`（模型与分块配置未改变）。
